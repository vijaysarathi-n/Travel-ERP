# Voyara — Travel & Tour Operator ERP (UI Prototype)

High-fidelity static HTML/CSS/JS prototype for an Indian travel-company ERP SaaS.

## Open locally
Open any HTML file in a browser (or serve with `python3 -m http.server 8080` from this folder).

## Structure
- `tokens.css` — design tokens (color, type, spacing, radius, shadows)
- `css/app.css` — layout + components
- `js/app.js` — shared shell (sidebar/header), icons, interactions, Chart.js defaults
- `js/chart.umd.min.js` — Chart.js 4.4.1
- `img/` — Unsplash destination photos (local)
- `screens/` — 1440×900 PNG screenshots (+ mobile dashboard)
- Screens: `index.html` (Dashboard), `enquiries.html`, `customers.html`, `customer.html`, `packages.html`, `package-new.html`, `package.html`, `bookings.html`, `booking.html`, `itinerary.html`, `hotels.html`, `transport.html`, `payments.html`, `invoice.html`, `suppliers.html`, `reports.html`, `components.html`
